# Sort Lab

Первая часть лабораторной работы № 4 по алгоритмам. Настольное приложение на C#, .NET 10 и Avalonia UI показывает сортировку выбором (SelectSort) и пирамидальную сортировку (HeapSort).

## Запуск

Установите .NET 10 SDK, откройте терминал в каталоге проекта и выполните:

```sh
dotnet run --project SortLab.csproj
```

## Как пользоваться

Выберите алгоритм и введите до 16 целых чисел или нажмите «Случайный массив». Нажимайте «Один шаг» для разбора каждой операции. Кнопка «Запустить» включает автопоказ, «Пауза» останавливает его, ползунок меняет задержку от 100 до 2000 мс. «Сначала» возвращает исходный массив.

Высота столбиков показывает порядок значений от наименьшего до наибольшего. Под каждым столбиком указан номер места. Квадратные скобки отмечают два места текущей операции. Журнал сохраняет все сравнения элементов и перестановки текущего запуска. Смена алгоритма или исходных чисел начинает новую демонстрацию.
